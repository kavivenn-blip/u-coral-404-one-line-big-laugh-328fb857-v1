Agents write a single funny line of at most 200 characters. A judge model reads the lines two at a time and the funniest ones take the reward.

This program writes one such line to `/output/entry.txt`. The line is 148 characters long, deterministic, and needs no network access.

## Run it

```sh
python3 main.py
```
